HOMEPAGE MESSAGES

Nav
  Everything you need is one click away: the features, the command line, install, the guide, the posts and the code.

Hero (badge, headline, lead)
  What Markdown is to words, Omasheet is to numbers: a plain-text spreadsheet that checks its own numbers, with SI units, exact arithmetic and typed columns, in files you can diff, review and hand to an AI.

Hero buttons
  Install it now, or star the project on GitHub.

Hero screenshot
  This is the app: a Sales sheet where Profit, Tax and Running are columns calculated from the others.

Facts strip
  It is one Rust binary on macOS, Windows and Linux, built on Polars, with no account and no cloud, under the MIT licence.

Section: What a binary workbook cannot do
  Formulas are written once per column, files are text, and every number keeps its meaning.

Feature 1, Text: The file is the spreadsheet
  An .omx file is readable text that diffs cleanly in Git, reviews like code and reads like a small typed program over its own data.

Feature 2, Units: Numbers that know their dimensions
  5kg + 300g is 5.3kg and 5kg + 3m is an error that says why, so a wrong unit can never pass as a number.

Feature 3, Types: Exact where it counts
  Fractions are exact without limit and Decimals keep money to the penny, so 1/3 + 1/6 is exactly 1/2.

Feature 4, Reports: Markdown in, finished report out
  Put a sheet inside a Markdown document and render it to HTML, so the numbers and the prose live in one reviewable file.

Feature 5, AI: Spreadsheets an LLM can't quietly break
  An agent skill lets Claude and friends write .omx files that type-check, so a wrong unit or type becomes an error and not a plausible wrong total.

Section: And the rest (six cards)
  Windowed columns: cum_sum, diff, rank and rolling_mean run in Polars, partitioned with "by".
  Built-in constants: pi, c, planck, kB and NA are in every file, from the 2019 SI and CODATA 2022.
  Real interchange: import and export XLSX, CSV, JSON and Parquet, with types and units kept where the format allows.
  Booleans and logic: symbol formats such as the tick and the cross, logic functions and gate operators, set right in the grid.
  Native, everywhere: one Rust binary with a Qt app on macOS, Windows, Arch and Omarchy that follows your dark and light mode.
  Listed in OmaStore: find Omasheet under Office in the community app store for Omarchy and install it with one click.

Section: Latest posts
  The three newest posts, each with its summary, lead to the full list of notes on building Omasheet.

Section: The same on the command line
  Everything the app does is scriptable, so sheets work in CI, in Git hooks and in agent loops.

Section: Install
  One line installs it on macOS, Omarchy, Arch and Windows, the same line updates it, and releases are checksummed with build provenance.

Install note
  It is early and changing and may contain errors, so there is a build-from-source route and a releases page for anything else.

Footer
  Omasheet is MIT licensed, by Stephen Roe, and the site, guide, posts and releases are one link away.
