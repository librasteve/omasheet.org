What Markdown is to words,Omasheet is to numbers.

A plain-text spreadsheet that checks its own numbers: SI units that understand dimensions, exact fractions and decimals, and typed columns. Files you can diff, review and hand to an AI.

What a binary workbook cannot do

Formulas are written once per column, files are text, and every number keeps its meaning.

Text

The file is the spreadsheet

An .omx file holds constants, functions and sheets as readable text. It diffs cleanly in Git, reviews like code, and round-trips through the app.

A formula is written once and applies down the whole column, so a sheet reads like a small, typed program over its own data.

const TaxRate = 20%

sheet Sales

| Month | Revenue | Cost | Profit | Tax |
| ----- | ------- | ---- | ------ | --- |
| Jan   | 10000   | 6000 | *      | *   |
| Feb   | 12000   | 7000 | *      | *   |

Profit  := Revenue - Cost
Tax     := Profit * TaxRate
Running := [Revenue; 0..*].sum()
Units

Numbers that know their dimensions

Write 5kg + 300g and get 5.3kg. Add a mass to a length and you get an error that says so, not a meaningless number.

All the SI prefixes, angles, time, binary data sizes, and uncertainty that carries through your arithmetic.

> 5kg + 300g
5.3kg
> 9.81m.s^-2 * 2s
19.62m.s^-1
> sin(45°30′30″)
0.713·
> 5kg ± 100g
5.00(10)kg
> 5kg + 3m
error: cannot add kg and m: they measure Mass and Length
Types

Exact where it counts

The numeric types run Integer < Fraction < Decimal < Float < Scientific < Complex, from exact to wide-ranging.

A Fraction is exact without limit, so 1/3 + 1/6 is 1/2. A Decimal(2) column keeps money to the penny.

Reports

Markdown in, finished report out

Put a sheet inside a Markdown document and render it to HTML with the same displays as the grid. The numbers and the prose stay in one reviewable file.

AI

Spreadsheets an LLM can't quietly break

Omasheet ships an agent skill, so Claude and friends write .omx files that type-check. When the model gets a unit or a type wrong, you get an error, not a plausible wrong total.

And the rest

Windowed columns

cum_sum, diff, rank and rolling_mean, partitioned with by, run in Polars.

Built-in constants

pi, c, planck, kB, NA and more, from the 2019 SI and CODATA 2022.

Real interchange

Import and export XLSX, CSV, JSON and Parquet, with types and units kept where the format allows.

Booleans and logic

Symbol formats such as ✓✗, logic functions and gate operators, set right in the grid.

Native, everywhere

One Rust binary with a Qt app on macOS, Windows, Arch and Omarchy. It follows your dark and light mode.

The same on the command line

Everything the app does is scriptable, so sheets work in CI, in Git hooks and in agent loops.

$ omasheet                              # the app, on a new file
$ omasheet examples/budget.omx          # open an .omx, .csv, .json or .xlsx
$ omasheet print examples/budget.omx    # print the calculated file
$ omasheet eval '1/3 + 1/6'             # 1/2, exactly
$ omasheet export budget.omx --xlsx     # or --csv --json --parquet
$ omasheet render report.md --html      # a Markdown report with live sheets

Install

Run the same line again to update. Releases are checksummed and carry build provenance.

macOS · Omarchy · Arch Linux

curl -fsSL https://raw.githubusercontent.com/librasteve/omasheet/main/install.sh | bash

Windows · PowerShell

irm https://raw.githubusercontent.com/librasteve/omasheet/main/install.ps1 | iex

Or search for Omasheet in OmaStore. Other Linux? Build from source. The latest is on the releases page. Early and changing; it may contain errors.
