What Markdown is to words,Omasheet is to numbers.

A text-native spreadsheet for technical workflows, with exact arithmetic, SI units, scientific uncertainty and typed columns. In files you can diff, review and hand to an AI.

What a binary workbook cannot do

Formulas are written once per column, files are plain text, and numbers keep their meaning. A spreadsheet you can understand, check, version and automate.

Text

The file is the spreadsheet

An .omx file is readable text that diffs cleanly in Git, reviews like code and reads like a small typed program over its own data.

A formula is written once and applies down the whole column, and the file round-trips through the app.

const TaxRate = 20%

sheet Sales

| Month | Revenue | Cost | Profit | Tax |
| ----- | ------- | ---- | ------ | --- |
| Jan   | 10000   | 6000 | *      | *   |
| Feb   | 12000   | 7000 | *      | *   |

Profit  := Revenue - Cost
Tax     := Profit * TaxRate
Running := [Revenue; 0..*].sum()
Units

Numbers that know their dimensions

5kg + 300g is 5.3kg; 5kg + 3m is an error that explains why. Dimensional analysis catches mistakes before they become plausible results.

All the SI prefixes, angles, time and binary data sizes, with uncertainty that carries through your arithmetic.

> 5kg + 300g
5.3kg
> 9.81m.s^-2 * 2s
19.62m.s^-1
> sin(45°30′30″)
0.713·
> 5kg ± 100g
5.00(10)kg
> 5kg + 3m
error: cannot add kg and m: they measure Mass and Length
Types

Exact numbers, scientific meaning

Fractions are exact without limit, Decimals keep money to the penny, and scientific notation carries uncertainty. From 1/3 + 1/6 = 1/2 to CODATA constants, numbers mean what they say.

The numeric types run Integer < Fraction < Decimal < Float < Scientific < Complex, from exact to wide-ranging.

And the rest

Windowed columns

cum_sum, diff, rank and rolling_mean run on Polars, with partitioning using by.

Built-in constants

pi, c, planck, kB and NA are ready in every file, drawing on the 2019 SI and CODATA 2022.

Real interchange

Import and export XLSX, CSV, JSON and Parquet, preserving types and units wherever the format allows.

Booleans and logic

Symbol formats such as ticks and crosses, logic functions and gate operators, all directly in the grid.

Native, everywhere

One Rust binary with a Qt app for macOS, Windows, Arch and Omarchy, following your dark and light mode.

The same on the command line

Everything the app does is scriptable, so sheets work in CI, Git hooks and AI-agent loops.

$ omasheet                              # the app, on a new file
$ omasheet examples/budget.omx          # open an .omx, .csv, .json or .xlsx
$ omasheet print examples/budget.omx    # print the calculated file
$ omasheet eval '1/3 + 1/6'             # 1/2, exactly
$ omasheet export budget.omx --xlsx     # or --csv --json --parquet
$ omasheet render report.md --html      # a Markdown report with live sheets

Install

Run the same line again to update. Releases are checksummed and carry build provenance.

macOS · Omarchy · Arch Linux

curl -fsSL https://raw.githubusercontent.com/librasteve/omasheet/main/install.sh | bash

Windows · PowerShell

irm https://raw.githubusercontent.com/librasteve/omasheet/main/install.ps1 | iex

Or search for Omasheet in OmaStore. Other Linux? Build from source. The latest is on the releases page. Early and changing; it may contain errors.
