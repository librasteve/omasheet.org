I came across this post from Arthur Augusto the other day:
> 
> I've been browsing my GitHub recommendations and finding interesting projects like OmaDesign, OmaPhotos, and Rawmakase. I've also been building OmaVM, aiming for a Parallels Desktop-like experience on Omarchy.
> 
> But discovering these apps and figuring out how to install them isn't always easy.
> 
> So I thought: what if I built a graphical interface on top of GitHub, added a few conventions, and let people discover, install, and uninstall applications?
> 
> That's the idea behind OmaStore:
> https://github.com/KitsuneSemCalda/OmaStore
> 
> ...
> 
> If you maintain an Omarchy app, would this publishing model work for your project? What would make it easier to adopt?

This seems perfect for potential users to discover and install Omasheet, so I signed up. A very simple process and a great showcase for the product will minimal effort.
